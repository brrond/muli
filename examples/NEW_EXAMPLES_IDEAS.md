# Future Example Ideas for Muli

This document contains ideas for additional constraint logic programming examples that could be added to the muli repository.

## Puzzles

1. **Kakuro** - Number crossword puzzle with sum constraints
2. **KenKen** - Arithmetic puzzle with cage constraints
3. **Latin Square** - Grid where each symbol appears once per row/column
4. **Pentomino Tiling** - Fit 12 pentomino pieces into a rectangle
5. **Nonogram** - Picture logic puzzle with row/column constraints
6. **Hashiwokakero (Bridges)** - Connect islands with bridges
7. **Slitherlink** - Loop drawing puzzle with number hints
8. **Nurikabe** - Island and sea puzzle
9. **Masyu** - Pearl puzzle with loop constraints
10. **Battleship** - Place ships on grid with constraints

## Scheduling Problems

11. **Class Timetabling** - Schedule classes avoiding conflicts
12. **Nurse Rostering** - Assign shifts to nurses with constraints
13. **Exam Scheduling** - Schedule exams avoiding conflicts
14. **Sports League Scheduling** - Create fair tournament schedules
15. **Conference Room Booking** - Allocate meeting rooms efficiently

## Optimization Problems

16. **Bin Packing** - Pack items into minimum number of bins
17. **Vehicle Routing** - Optimize delivery routes with constraints
18. **Set Covering** - Cover all elements with minimum sets
19. **Warehouse Location** - Optimal placement of warehouses
20. **Cutting Stock** - Minimize waste when cutting materials

## Logic Problems

21. **SAT Solver** - Boolean satisfiability problem
22. **Logic Grid Puzzles** - Deduction puzzles with clues
23. **Cryptogram** - Decode substitution ciphers
24. **Nonogram Solver** - Automated picture puzzle solver
25. **Boolean Circuit Satisfiability** - Find valid circuit inputs

## Games

26. **Mastermind** - Code-breaking game with feedback
27. **River Crossing** - Classic puzzle with constraints
28. **Tower of Hanoi Variants** - Extended versions with rules
29. **Peg Solitaire** - Board game with jump constraints
30. **15-Puzzle** - Sliding tile puzzle

## Graph Problems

31. **Hamiltonian Path** - Find path visiting all vertices once
32. **Clique Finding** - Find maximum clique in graph
33. **Independent Set** - Find maximum independent set
34. **Vertex Cover** - Minimum vertices to cover all edges
35. **Graph Isomorphism** - Check if graphs are identical
